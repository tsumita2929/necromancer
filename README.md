# Necromancer

Find the dead in your dependency tree. Raise your code on living ones.

Necromancer reads a project's dependencies, finds the ones that are dead
(deprecated, archived, unmaintained or carrying unpatched advisories), and moves
the project to living successors with a Kiro spec and a differential
property-based test.

Status: in development for Kiroween 2026, category Resurrection.
